# 탭 녹화 확장 (Chrome·Edge·Brave·Arc)

브라우저 탭 하나의 화면과 소리만 녹화해 MacRecorder 에 저장합니다. 여러 탭을 동시에 녹화할 수 있고, 녹화한 탭은 MacRecorder 대시보드 목록에 따로 들어가 전사·요약도 똑같이 됩니다.

- 뒤에 있는 탭(다른 탭을 보고 있는 동안)도 계속 녹화됩니다.
- 탭 소리는 녹화하는 동안에도 스피커로 들립니다. 다른 탭·다른 앱 소리와 알림음은 들어가지 않습니다.
- 마이크(내 목소리)를 같이 녹음할 수 있습니다(기본 켬, 팝업에서 끄기·장치 고르기).
- 맥 화면 기록 권한이 필요 없습니다. 브라우저가 탭을 직접 녹화합니다.

Safari 는 이 확장을 쓸 수 없습니다. Safari 창은 MacRecorder 의 «창 녹화»를 쓰세요.

## 설치 (한 번)

MacRecorder 서버가 켜져 있어야 합니다(메뉴바 아이콘이 보이면 켜져 있습니다).

1. 브라우저 주소창에 확장 관리 페이지를 엽니다.
   - Chrome: `chrome://extensions` · Edge: `edge://extensions` · Brave: `brave://extensions` · Arc: `arc://extensions`
2. 오른쪽 위 «개발자 모드»를 켭니다.
3. «압축해제된 확장 프로그램을 로드합니다»(Load unpacked)를 누르고 MacRecorder 설치 폴더 안의 `extension` 폴더를 고릅니다. 설치 폴더는 `macrec version` 으로 확인합니다.
4. 퍼즐 모양 아이콘에서 «MacRecorder 탭 녹화»를 고정(핀)해 두면 쓰기 편합니다.

업데이트한 뒤에는 확장 관리 페이지에서 이 확장의 새로고침(↻) 버튼을 한 번 누릅니다.

## 쓰는 법

1. 녹화할 탭으로 가서 확장 아이콘을 누릅니다.
2. «마이크도 같이 녹음»을 켜거나 끄고, 필요하면 마이크를 고릅니다.
3. «이 탭 녹화»를 누릅니다. 아이콘에 `REC` 가 붙습니다.
4. 다른 탭도 녹화하려면 그 탭에서 1~3을 반복합니다.
5. 팝업에서 일시정지·다시 녹화·정지를 누릅니다. 녹화 중인 다른 탭도 팝업 아래 «녹화 중인 탭»에서 멈출 수 있습니다.

다음 경우에는 녹화가 저절로 끝나고 지금까지 녹화한 것이 저장됩니다.

- 녹화 중인 탭을 닫았을 때
- MacRecorder 대시보드에서 그 녹화의 정지를 눌렀을 때

대시보드의 일시정지·다시 녹화 버튼도 5초 안에 확장에 전달됩니다.

### 마이크를 처음 켤 때

확장은 처음 한 번 마이크 권한을 받아야 합니다. «이 탭 녹화»를 눌렀을 때 «마이크 허용» 페이지가 열리면 «마이크 허용» → 브라우저 창에서 «허용»을 누르고, 녹화할 탭으로 돌아가 다시 누릅니다. 이 권한을 받아야 팝업에 마이크 이름이 보입니다.

macOS 가 브라우저의 마이크 사용을 막고 있으면 시스템 설정 → 개인정보 보호 및 보안 → 마이크에서 그 브라우저를 켜세요.

## 저장되는 것

- 녹화마다 MacRecorder 녹화 폴더에 항목 하나가 생깁니다. 대시보드 목록에서 탭 제목으로 보입니다.
- 녹화하는 동안 2초마다 조각을 서버에 올리므로, 브라우저가 갑자기 꺼져도 그때까지 녹화한 것은 남습니다.
- 일시정지한 시간은 파일에 들어가지 않습니다.
- 화면 크기는 탭 크기 그대로(레티나는 2배, 폭 최대 1920)입니다.

## 설정

팝업 아래 «설정»에서 서버 포트를 바꿀 수 있습니다. 설치할 때 `--port` 로 포트를 바꿨다면 여기도 같은 값으로 맞춥니다(기본 7931).

## 안 될 때

| 증상 | 확인할 것 |
|---|---|
| «MacRecorder 서버가 꺼져 있습니다» | 메뉴바 아이콘이 있는지, `macrec doctor`. 포트를 바꿨다면 확장 설정의 포트 |
| «이 탭 녹화»가 회색 | `chrome://` 같은 브라우저 설정 페이지와 확장 페이지는 녹화할 수 없습니다 |
| 마이크가 녹음되지 않음 | 위 «마이크를 처음 켤 때». 고른 마이크가 빠져 있으면 기본 마이크로 녹음합니다 |
| 녹화 목록에 «오류» | 대시보드에서 그 녹화를 지웠거나 서버를 바꿨을 때입니다. 팝업의 «닫기»로 지우고 다시 시작합니다 |
| «서버에 올리는 중 지연» | 서버가 잠시 응답하지 않는 동안입니다. 녹화는 계속되고, 서버가 돌아오면 밀린 조각부터 올립니다 |

## 개발자용

- 구조: `background.js`(서비스 워커, 상태·배지) → `offscreen.js`(MediaRecorder, 탭마다 하나) → MacRecorder 서버 `/api/tabs/*`.
- 형식: `video/webm;codecs=h264,opus` 를 먼저 쓰고, 안 되면 vp9 → vp8 순서. 조각은 2초(`timeslice`), 첫 조각에 webm 헤더가 있어 서버는 조각을 순서대로 이어 붙이면 됩니다.
- offscreen 문서를 먼저 만들고 나서 `tabCapture.getMediaStreamId` 를 부릅니다. 순서가 바뀌면 offscreen 이 그 ID 를 열지 못합니다(`Requested device not found`).
- 탭 캡처는 `maxWidth`·`maxHeight` 크기에 검은 띠를 씌워 맞추므로, 탭과 같은 비율의 정확한 크기를 min·max 로 같이 줍니다.
